[daisyUI FAB](https://daisyui.com/components/fab/) — speed dial (stacked) or **flower** (quarter circle). **`FabTrigger`** → optional **`FabClose`** or **`FabMainAction`** (not both) → **`FabAction`**s.

**`fab-preview`** only in these docs so the demo isn’t full-viewport. **daisyUI ≥ 5.5** for `fab` styles.

- **`Fab`** — Root; **`flower`** for flower layout. Styling lives on **`FabTrigger`** / **`FabAction`**.
- **`FabTrigger`** — First. [Button](/docs/components/actions/button) props.
- **`FabClose`** / **`FabMainAction`** — Optional; one or neither.
- **`FabAction`** — Dial item; optional `label` (beside the icon on circle actions). **`modifier="circle"`** by default; **`modifier="text"`** for full text in the button (no **`btn-circle`**).
- **`FabMark`** — ✕ inside **`FabClose`**; [Button](/docs/components/actions/button) props.
- **`variant="single"`** — No dial; [Button](/docs/components/actions/button) props on **`Fab`**.
